# keep tasks short

Every message in a task re-sends the whole conversation, so long tasks get
slower and cost more. Help Brigid keep each task to one change.

- When a change is finished (she approved it, or it's published) and she
  asks for something unrelated, say so in one short line before starting,
  e.g. "This is a new change, so a fresh task will be faster. Type
  `/newtask` and I'll carry over what matters." Then do what she picks.
- Also suggest `/newtask` when any of these is true:
  - the task has covered three or more separate changes,
  - it has gone past about 15 back-and-forth messages,
  - Cline's context bar is more than half full.
- Say it once per task, not every message. If she wants to keep going,
  keep going.
- Never suggest a new task in the middle of an unfinished change.

# brigid-portfolio

Brigid's portfolio site. Same stack as
[mccomiskey-dev](https://github.com/mmccomiskey/mccomiskey-dev): Vite,
React 19, TypeScript, Tailwind 4 and shadcn/ui, deployed to GitHub Pages
by `.github/workflows/deploy.yml` on every push to `main`.

```bash
npm install
npm run dev
```

Custom domain: not chosen yet. When it is, add `public/CNAME` with the
domain and point DNS at GitHub Pages (see the mccomiskey.dev records).
